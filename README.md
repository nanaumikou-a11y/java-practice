# java-practice

Progateを中心に学習しているJavaの基礎およびオブジェクト指向の練習コードまとめです。

## 現在の学習状況
- **学習済み・理解を深めている内容**
  - クラス定義とインスタンス化、コンストラクタを使ったデータ管理
  - インスタンスメソッドの定義と役割分担
  - メソッドの引数と戻り値、標準ライブラリを活用した処理（BMI計算・`Math.round` による数値整形など）
  - 再帰処理の仕組み（階乗計算など）
- **今後の学習予定**
  - 継承やカプセル化など、オブジェクト指向のさらなる応用
  - 学習した内容を活かした簡単なコンソールアプリ・ミニツールの作成

## 収録コード・演習テーマ
- **BMI計算（クラス・インスタンス化・メソッド練習）**: 人物データとBMI計算・丸め処理をクラス設計の中で整理したコード
- **再帰処理の練習（階乗計算など）**: 終了条件や戻り値を意識しながら再帰呼び出しの流れを確認したコード

## 学習の進め方
学んだ単元ごとにコードを作成し、振り返りや改善を行いながら少しずつリポジトリに追加していく予定です。
