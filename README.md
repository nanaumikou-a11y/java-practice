# java-practice

Progateを中心に学習しているJavaの基礎およびオブジェクト指向の練習コードまとめです。

## 現在の学習状況
- **学習済み・理解を深めている内容**
  - クラス定義とインスタンス化（`new` によるオブジェクト生成）
  - コンストラクタを使ったフィールドの初期化
  - インスタンスメソッドの定義と役割分担（戻り値のある処理・`void` の処理）
- **今後の学習予定**
  - メソッドの応用、継承やカプセル化などのオブジェクト指向の学習
  - 学習した内容を活かした簡単なコンソールアプリ・ミニツールの作成

## 収録コード
- **`bmi.java`**: `Person` クラスとインスタンスを使ったBMI計算・表示の練習コード

## 学習の進め方
Javaの学習が一周でき次第Javascriptの学習を進めていく予定です。
